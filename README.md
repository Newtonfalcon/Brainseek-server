# Brainseek-server
BrainSeek is an AI researcher that helps students and researchers write academic papers by pulling factual data from the web and synthesizing it into well-structured, factual, and academic-ready text.

It integrates Google Gemini, Wolfram Alpha, and Tavily API to ensure every response is accurate, data-driven, and up-to-date — all stored and managed through a MongoDB database.

🚀 Features

🔍 Factual Web Research: Uses Tavily API and Google Gemini to fetch the most relevant and trustworthy data.

🧠 AI-Assisted Writing: Generates clear, well-structured academic content.

📊 Computation & Data: Powered by Wolfram Alpha for accurate math, stats, and scientific results.

🧩 MongoDB Integration: Saves and manages user research data and session history.

🧾 Citation-Ready Output: Automatically provides reference data and factual insights.

🧰 Tech Stack
Layer	Technologies
Frontend	React (NEXTJS + Tailwind CSS)
Backend	Node.js + Express
Database	MongoDB
AI & APIs	Google Gemini API · Wolfram Alpha API · Tavily API
